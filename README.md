# Swish Club — Free Throw Challenge

A basketball free throw game built with HTML, CSS, and JavaScript. Take ten shots each round. Aim with your mouse or finger, hold to charge your power, then release to shoot.

## Run the game

1. Save `index.html`, `style.css`, and `game.js` in the same folder.
2. Open `index.html` in a modern web browser.
3. Move your mouse or finger over the court to aim.
4. Hold the mouse button or touch the court to charge your shot, then release to shoot.
5. Select **NEW GAME** to start another round.

No installation or build step is required. The game uses Google Fonts when online and falls back to system fonts when offline.

## Files

- `index.html` — game page, score display, and canvas.
- `style.css` — page layout and visual styling.
- `game.js` — court drawing, aiming, shot physics, scoring, and round reset.

## Controls

- Move the mouse or finger to aim.
- Hold to charge shot power.
- Release to shoot.
- Select **NEW GAME** to reset the round.
